Right Foot

An alarm that stops only when you scan a code away from your bed.

The alarm doesn't ring

Allow Alarms in Settings › Apps › Right Foot.

I can't find my code

Tap "Can't find the code?" on the alarm screen. You get five emergency stops a month.

My code is gone

Settings › Manage codes › pick the code › Update code, then scan a new one. Alarms using it keep working.

Apps aren't blocked

Right Foot needs Screen Time access. Allow it when the app asks, or in Settings › Screen Time.
